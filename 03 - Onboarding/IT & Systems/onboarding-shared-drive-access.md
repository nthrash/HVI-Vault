# Shared Drive Access

## Navigating to the HFICU Signout

**Start Menu** > **File Explorer** > **PHI_Access$ (\\\\clinisilonhh) (P:)** > Search **APP** > **PHI-TMC - APP Team Shared** > **Signouts** > **Heart Failure** > **HFICU Signout**

## Updating the Signout Date

The HFICU signout title has a changing date that you must manually update each day.

### Steps

1. Right-click the current signout document and **Copy** it
2. **Paste** it within the same folder
3. Rename the new copy to the appropriate date
4. Drag the older document into the **Archived Signout** folder

> All documents must be **closed** before renaming or moving them.

### Example

- `HFICU Signout 03.14.26.docx` is copied and pasted
- A new file appears as `HFICU Signout 03.14.26 - Copy.docx`
- Rename the copy to `HFICU Signout 03.15.26.docx`
- Move the original into the **Archived Signout** folder

This keeps a running record so we can reference previous signouts if needed.

> The **Morning Text.docx** file is also located in the Heart Failure folder. For details on who receives it and when to send it, see [Signout](../Unit%20Operations/onboarding-signout.md).
