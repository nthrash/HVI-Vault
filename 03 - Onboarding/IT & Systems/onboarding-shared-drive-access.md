# Shared Drive Access
Start Menu -> File Explorer -> PHI_Access$ (\\clinisilonhh) (P:) -> Search APP -> PHI-TMC - APP Team Shared -> Signouts -> Heart Failure -> HFICU Signout

The HFICU signout title has a changing date you have to manually update.

How to: Right click and copy the document, then paste it within the same folder. From there you can rename the document to the appropriate date. Drag the older document and place it into the Archived Signout folder. This allows us to keep record of changes and go back if needed for any reason. 

For example: HFICU Signout 03.14.26.docx gets copied and pasted into the same folder and a new document will show up listed ad HFICU Signout 03.14.26 - Copy.docx. We then rename the copy document as HFICU Signout 03.15.26 and move the old document to the archive folder. 
The documents must be closed when modifying any name or moving its location.
