# Hospital Policies

All Memorial Hermann hospital policies and procedures are available on the **PolicyTech** intranet portal:

**[https://memorialhermann.policytech.com](https://memorialhermann.policytech.com)**

> **Note:** This site is only accessible from the hospital network or via the remote access portal.

## How to Find Policies

1. Navigate to the PolicyTech link above
2. Use the **search bar** to look up policies by keyword or policy number
3. Browse by department or category to find relevant procedures

## Key Policies to Review

As a new team member, familiarize yourself with the following categories:

- **Infection Control** — Hand hygiene, PPE, isolation precautions
- **Patient Safety** — Fall prevention, medication safety, restraint use
- **Code Procedures** — Code Blue, Rapid Response, Code Stroke
- **Documentation** — Charting standards, verbal order policies
- **HIPAA / Privacy** — Patient information handling and disclosure
