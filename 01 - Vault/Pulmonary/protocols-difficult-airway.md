# Difficult Airway Management

---

## 1. Recognition — LEMON Assessment

| Letter | Component | Details |
|--------|-----------|---------|
| **L** | Look | Does the patient look like a difficult intubation? Syndromic features, obesity, trauma |
| **E** | Evaluate (3-3-2 rule) | See below |
| **M** | Mallampati score | Score >2 (barely visible uvula) = ↑ risk |
| **O** | Obesity / Obstruction | Morbid obesity; abscess, mass, angioedema, foreign body |
| **N** | Neck mobility | Restricted range = difficulty aligning airway axes |

### 3-3-2 Rule
| Measurement | Threshold | Method |
|-------------|-----------|--------|
| Mouth opening | <3 finger widths (<3 cm) = difficult | Patient opens mouth fully |
| Thyromental distance | <3 finger widths (<6 cm) = difficult | Thyroid cartilage to chin |
| Hyoid-to-thyroid distance | <2 finger widths | Hyoid bone to thyroid notch |

*Note: Thyromental distance <6 cm: OR 4.8 for difficult intubation (sens 53%, spec 79%). Mallampati 3–4: OR 3.0 (sens 33%, spec 91%). No single predictor is sufficient — use in combination.*

---

## 2. History Red Flags

- Prior documented difficult intubation
- Airway-altering changes since last anesthetic (weight gain, C-spine surgery, head/neck radiation)
- OSA, obesity, snoring

### Conditions Associated with Difficult Airway

| Category | Examples |
|----------|---------|
| Airway edema/trauma | Recent intubation, angioedema, burns, infection |
| Anatomic obstruction | Mediastinal mass, retrosternal goiter, subglottic stenosis |
| Structural | Ankylosing spondylitis, degenerative C-spine/jaw arthritis, kyphosis |
| Endocrine/metabolic | Acromegaly |
| Macroglossia | Down syndrome, Pierre Robin, hypothyroidism |
| Syndromes | Treacher-Collins (malar/mandibular hypoplasia), Klippel-Feil (C-spine fusion), Goldenhar |

---

## 3. Physical Exam Predictors

| Feature | Concern |
|---------|---------|
| Long upper incisors / prominent overbite | Limits blade insertion angle |
| Inability to prognath (protrude jaw) | Poor visualization |
| Mouth opening <3 cm | Cannot admit laryngoscope blade comfortably |
| Mallampati 3–4 | Limited pharyngeal visualization |
| Thyromental distance <6 cm | Poor laryngeal exposure |
| Sternomental distance <12 cm | Restricted head extension |
| Thick/short neck | Limits positioning |
| Beard | Impairs mask seal |
| Edentulous | Easier to intubate; harder to bag-mask ventilate |

---

## 4. Imaging (When Applicable)

| Modality | Use |
|----------|-----|
| Lateral neck X-ray | Mandibular length, posterior mandibular depth, atlanto-occipital gap |
| CT neck/airway | Subglottic/laryngeal stenosis, abnormal turbinate anatomy (nasal), tracheomalacia, surgical airway planning |

## 5. Equipment for Difficult Airway

- Face mask + BVM + HME filter
- Oropharyngeal airways (multiple sizes)
- Nasopharyngeal airways (multiple sizes)
- Macintosh blades (size 3 and 4) + short handle
- **Video laryngoscope** (McGrath or equivalent)
- ETT × 2 (standard + one size smaller)
- **Bougie** (endotracheal tube introducer)
- Malleable blunt stylet
- **LMA** (standard, multiple sizes)
- Long airway exchange catheter
- **Surgical cricothyroidotomy kit**
- Kink-resistant cricothyroidotomy cannula + jet ventilation kit
- Capnograph / colorimetric EtCO₂ detector

---

## 6. Pre-Intubation Preparation

### Team Preparation
- Assign roles: airway proceduralist, airway assistant, drug administrator
- Designate who applies BURP / external laryngeal manipulation
- Confirm who pushes drugs and who runs for supplies
- Brief team on Plan A and Plan B (and Plan C if needed)

### Patient Preparation
- Explain procedure to patient if able
- Pre-oxygenate **3–5 minutes** (NRB 15 LPM or HFNC)
- Position optimally: **ramped position** for obese patients (ear to sternal notch)

### Equipment Check
- Plan A: all within reach and confirmed functional
- **Plan B ready within 60 seconds** (within arms reach)
- Drugs drawn up: induction agent, paralytic, push-dose vasopressor, sedation infusion
- EtCO₂ confirmed functional and within reach
- Suction on at maximum, Yankauer in hand

## 7. Pre-Intubation Checklist

- [ ] Face mask + BVM + HME filter
- [ ] Oropharyngeal airway (sized)
- [ ] Yankauer suction — at max suction
- [ ] Video laryngoscope (McGrath) — powered on, checked
- [ ] Bougie
- [ ] ETT × 2 — balloon tested
- [ ] EtCO₂ device
- [ ] Induction agent drawn up
- [ ] Paralytic drawn up
- [ ] Hemodynamic support agent drawn up (push-dose epinephrine or phenylephrine)
- [ ] Post-intubation sedation ready
- [ ] Surgical cric kit — confirmed location
