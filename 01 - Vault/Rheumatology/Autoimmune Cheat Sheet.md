# Rheumatology Cheat Sheet for APPs

---

## Rheumatoid Arthritis (RA)

| Category | Details |
|---|---|
| **Clinical Presentation** | Symmetrical joint pain, morning stiffness >30 min, joint swelling |
| **Laboratory Tests** | RF Factor (RF) — Positive in ~70–80% of pts |
| | Anti-CCP — High specificity for RA |
| | ESR and CRP: Elevated indicating inflammation |
| **Imaging** | X-Rays — joint space narrowing, erosions |
| | MRI — more sensitive for early joint issues |
| **Diagnostic Criteria** | At least 6/10 on the ACR/EULAR Classification criteria |
| **Treatment** | NSAIDs |
| | DMARDs — Methotrexate for long-term control |
| | Biologics: TNF inhibitors for severe cases |

## Systemic Lupus Erythematosus (SLE)

| Category | Details |
|---|---|
| **Clinical Presentation** | Malar rash, photosensitivity, oral ulcers, arthritis, renal involvement |
| **Laboratory Tests** | ANA — positive in >95% of cases |
| | Anti-dsDNA and Anti-Smith antibodies: Highly specific for SLE |
| | Anti-RNP |
| | Complement levels (C3, C4): Often low during active disease (Flare) |
| **Biopsy** | Renal biopsy: Necessary if lupus nephritis is suspected |
| **Diagnostic Criteria** | SLICC or ACR criteria: Require a combination of clinical and immunologic criteria |

### SLE Diagnostic Criteria Detail

1. **Clinical Criteria:** Acute cutaneous lupus (e.g., malar rash), chronic cutaneous lupus (e.g., discoid rash), oral ulcers, non-scarring alopecia, synovitis (in two or more joints), renal disorder (proteinuria >0.5g/24h), and neurological disorder
2. **Immunologic Criteria:** Positive ANA, anti-dsDNA, anti-Sm, antiphospholipid antibodies, low complement (C3, C4, or CH50), and direct Coombs' test in the absence of hemolytic anemia
3. **Diagnosis:** SLE is diagnosed if a person has at least four criteria (including at least one clinical and one immunologic criterion) or biopsy-proven lupus nephritis with positive ANA/anti-dsDNA

## Sjogren's Syndrome

| Category | Details |
|---|---|
| **Clinical Presentation** | Sicca symptoms (dry mouth, dry eyes, parotid gland enlargement) |
| | May present with extraglandular manifestations such as arthritis, interstitial nephritis, or peripheral neuropathy |
| **Laboratory Tests** | ANA and RF often positive |
| | Anti-Ro/SSA and Anti-La/SSB antibodies: Specific markers |
| **Diagnostic Tests** | Schirmer Test — assess tear production |
| | Labial Salivary Gland Biopsy — confirms lymphocytic infiltration |
| **Treatment** | Symptomatic management with artificial tears, saliva stimulants |
| | Hydroxychloroquine for arthritis and fatigue |
| | Immunosuppressants reserved for severe organ involvement |

---

## Vasculitis Syndromes (Wegener's Granulomatosis)

| Category | Details |
|---|---|
| **Clinical Presentation** | Sinusitis, glomerulonephritis, pulmonary infiltrates, systemic symptoms like fever, nasal bridge collapse |
| **Laboratory Tests** | c-ANCA (PR3-ANCA): Highly specific |
| | Elevated ESR, CRP |
| **Treatment** | Corticosteroids: High doses for induction |
| | Cyclophosphamide/Rituximab: For severe organ involvement |
| | Maintenance: Azathioprine or methotrexate |

---

## Mixed Connective Tissue Disease (MCTD)

| Category | Details |
|---|---|
| **Clinical Presentation** | Overlapping features of SLE, Scleroderma, and polymyositis (mostly women) |
| | PAH is major cause of morbidity and mortality |
| **Laboratory Tests** | Anti-U1-RNP Antibodies |
| | ANA — usually speckled |
| | CK may be elevated in myositis |
| | Normal C3, C4 — helps distinguish from lupus flare |
| **Diagnostic Criteria** | High anti-U1-RNP and 2–3 features of other autoimmune diseases |
| | Raynaud's, swollen hands, synovitis, myositis, acrosclerosis (skin thickening) |

## Scleroderma (Systemic Sclerosis)

| Category | Details |
|---|---|
| **Clinical Presentation** | Fibrosis of skin and organs, vascular abnormalities, immune dysregulation |
| | Localized (limited to skin) or systemic (SSc) — affects heart, lungs, GI, kidneys |

### Scleroderma Categories

- **Diffuse Cutaneous Systemic Sclerosis (dcSSc)** — Rapid progression, internal and external involvement, causes ILD
- **Limited Cutaneous Systemic Sclerosis (lcSSc)** — Skin involvement first, later organ involvement, causes PAH
  - Associated with CREST Syndrome (Calcinosis, Raynaud's, Esophageal dysmotility, Sclerodactyly, Telangiectasia)

### Scleroderma Labs and Diagnostics

| Test | Significance |
|---|---|
| Anti-centromere | lcSSc, PAH, good prognosis |
| Anti-Scl-70 | dcSSc, ILD, worse prognosis |
| Anti-RNA polymerase III | Scleroderma renal crisis, rapid skin progression |
| ANA | Almost always positive |
| HRCT | To evaluate for ILD |

### Scleroderma Treatment

| Manifestation | Treatment |
|---|---|
| Skin thickening | MTX, MMF, cyclophosphamide |
| ILD | MMF, cyclophosphamide, nintedanib |
| PAH | PAH-specific treatments |
| Raynaud's | CCB, PDE5 inhibitors, topical nitrates |
| Renal crisis | ACE inhibitors (avoid steroids) |
| GI symptoms | PPI, prokinetics, antibiotics for SIBO |

### Scleroderma Prognosis

Poorer prognosis in diffuse disease, males, anti-Scl-70+, African descent — with ILD being the leading cause of death.
